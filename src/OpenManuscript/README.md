# OpenManuscript Sublime Text Plugin

Navigate your OpenManuscript project from inside Sublime Text 4.

---

## Repository layout

```
openmanuscript/
├── src/
│   ├── oms                        ← apply oms_patch.py changes here
│   ├── openms/
│   │   ├── sublime.py             ← copy here
│   │   └── ...
│   └── ...
└── sublime/
    └── OpenManuscript/            ← copy this folder to Sublime packages
        ├── OpenManuscript.py
        ├── Default.sublime-keymap
        ├── Main.sublime-menu
        └── README.md
```

---

## What it does

- **Chapter & scene navigator** — a flat quick panel listing all chapters and
  their scenes. Select a chapter to open its first scene, or select any scene
  to open it directly.
- **Jump to manuscript.yaml** — open the project definition file instantly.
- **Word count stats** — per-chapter word counts in an output panel.

## Installation

### 1. Add to the openmanuscript repo

Copy `sublime.py` into `src/openms/`:

```bash
cp sublime.py src/openms/sublime.py
```

Apply the two changes from `oms_patch.py` to `src/oms`:

- Add `import openms.sublime` near the top, after `import openms`
- Add the `sublime` subparser block before the final `args = parser.parse_args()` line

### 2. Copy the plugin to Sublime Text

Copy the `OpenManuscript/` folder to your Sublime Text packages directory:

```bash
cp -r sublime/OpenManuscript/ \
  ~/Library/Application\ Support/Sublime\ Text/Packages/
```

| Platform | Packages path |
|----------|---------------|
| macOS    | `~/Library/Application Support/Sublime Text/Packages/` |
| Linux    | `~/.config/sublime-text/Packages/` |
| Windows  | `%APPDATA%\Sublime Text\Packages\` |

If you're unsure of the path, find it from inside Sublime via
**Preferences → Browse Packages...**.

### 3. Install PyYAML into the plugin folder

Sublime Text 4 uses its own Python interpreter, so install PyYAML directly
into the plugin folder:

```bash
pip install --target \
  ~/Library/Application\ Support/Sublime\ Text/Packages/OpenManuscript/ \
  pyyaml
```

### 4. Verify the sys.path fix is in place

Make sure the top of `OpenManuscript.py` has these lines before `import yaml`:

```python
import sys
import os
sys.path.append(os.path.dirname(__file__))
```

This ensures Sublime's Python can find the PyYAML package installed in step 3.

### 5. Open your project with `oms sublime`

From inside any manuscript directory:

```bash
# use the current directory
oms sublime

# or point at a specific directory
oms sublime --manuscriptdir ~/manuscripts/my-novel
```

This will:
1. Find `manuscript.yaml` (searching upward from the given directory)
2. Write `<projectname>.sublime-project` next to it (or update it if it exists)
3. Open the project in Sublime Text

## Keyboard shortcuts

| Keys | Action |
|------|--------|
| `Cmd+Shift+M` | Navigate chapters & scenes |
| `Cmd+Shift+Y` | Open manuscript.yaml |
| `Cmd+Shift+W` | Show word count stats |

Change them in `Default.sublime-keymap` or via **Preferences → Key Bindings**.

---

## Menu

All commands are also available under **Tools → OpenManuscript**.

## Manual project setup (without `oms sublime`)

If you prefer to configure the project file yourself, add this to your
`.sublime-project` file:

```json
{
    "folders": [
        { "path": "." }
    ],
    "settings": {
        "manuscript_yaml": "manuscript.yaml"
    }
}
```

The plugin will also auto-detect `manuscript.yaml` in the first project folder
or the directory of the currently open file, so the settings key is optional
if your layout is straightforward.
